# PC开发者模式：密码入口与画面优先

本文对应[main整合基线 Baseline27](BASELINE/27_MAIN_DEVELOPER_PRIORITY_BASELINE_2026-11-11.md)：Rust/portable 2.0.26、Flutter 2.0.26+59，开发者画面优先功能来源25bc2ce。描述源码行为；历史双端编排仅有HTTP204受理记录，结果未知，多PC与语音真机验收仍待证。

## 进入与退出

1. 在PC主窗口按Ctrl+Shift+H，打开开发者密码框。
2. 输入已配置的任一有效密码，点击确认或按Enter/小键盘Enter。密码精确匹配，区分大小写，前后空格也参与校验。
3. 成功后启用本次进程的免登录入口和native开发者模式。新建或重新连接Android会话时生效；已经连接的窗口需要重连。

密码错误时不会启用模式，弹窗保留，可继续修改并提交；没有“输错一次以后不能再打开”的限制。取消或Esc关闭弹窗，之后可以再次按快捷键打开。“不叠加弹窗”只表示已有一个密码框时，重复快捷键不会再开第二个。成功解锁后同一进程不再弹框；彻底退出并重新启动PC程序后回到未解锁状态。

## 多PC连接行为

A为普通PC，B为开发者PC；两者连接同一Android，并通过原有端点认证。

| 场景 | A普通PC | B开发者PC |
|---|---|---|
| 没有开发者连接 | 维持原有画面、操作和语音行为 | — |
| A已连接且正在通话，B加入 | 暂停画面及操作，保留会话和语音 | 正常接收画面和控制 |
| B已连接，A新建或重新连接 | 暂停画面及操作，仍可使用原有语音邀请/接听流程 | 正常接收画面和控制 |
| 多个开发者连接 | 持续暂停画面及操作 | 各开发者均可接收和控制 |
| 最后一个开发者离开 | 恢复画面资格，收到新帧后显示；恢复操作 | — |

暂停覆盖普通视频、截图、ADB H.264/JPEG/节点穿透画面，以及普通PC的触摸、键盘、粘贴、Shell变更、采集和黑屏开关。连接、心跳、状态与ZEGO语音链路保留。暂停后隐藏旧画面，避免继续对静止画面盲操作；暂停或恢复不重启Android采集服务、不重新申请MediaProjection权限。

语音继续使用原有邀请、接听、发送、接收及忙状态规则；此功能没有新增并发通话能力。开发者断网或崩溃后，要等原有连接存活检测与清理移除最后一个开发者会话，普通PC才恢复。恢复依赖实际采集源有新帧，不伪造画面就绪。

## 版本与认证边界

- 完整功能需要PC与Android均升级到包含该协议的版本。旧Android不实施优先策略，新PC会提示不支持。
- 旧PC连接新Android时按普通角色处理，发送端仍过滤其画面和操作，但旧PC没有新的暂停说明UI。
- 开发者密码只解锁本地模式，不能替代远端密码或其他端点认证。认证失败的连接不参与优先策略。
- `developer_mode`是已授权客户端的协作声明，修改版客户端可以伪造角色；本方案不提供服务端签名的开发者身份。安全边界见[ADR-0028](ADR/0028-developer-screen-priority.md)。

## 维护密码与实现位置

两个有效密码以SHA-256摘要保存在`flutter/lib/models/developer_login_bypass_model.dart`的`_developerLoginPasswordHashes`中，所以搜索明文不会命中。新增或替换时，将新密码按UTF-8计算SHA-256，把小写64位十六进制摘要加入集合或替换对应旧项；需继续生效的旧项保留。不要在文档、日志或提交说明记录明文，重新编译PC并更新安装后才影响用户程序。

维护后分别在全新、未解锁的进程中验证两个有效密码、错误密码、取消/Esc、关闭后再次打开、重复快捷键及已有会话重连。当前任务仅同步文档，不执行这些运行验证。

工程入口：弹窗在`connection_page.dart`；native入口为`openworld_enable_developer_mode()`；Android连接注册在`src/developer_mode.rs`，纯策略在`src/screen_policy.rs`，跨端字段在`libs/hbb_common/protos/message.proto`。完整链路见[模块设计](AI_ENGINEERING/03_MODULE_DESIGN.md)、[协议](AI_ENGINEERING/06_NETWORK_PROTOCOL.md)、[ADB媒体与输入](AI_ENGINEERING/14_ADB_MIRROR.md)；验收见[TEST_MATRIX](../TEST_MATRIX.md)的FLT-08及DSP-01—10。
